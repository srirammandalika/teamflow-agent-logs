## Request
Build a user authentication landing page for the app.

1. Create dashboard/login.html — a login/register page that matches the existing 
   style of dashboard/index.html. Include a tab to switch between Login and Register 
   forms. Each form has email + password fields and a submit button.

2. Add a users table to db/init.sql with columns: id (serial primary key), 
   email (text unique not null), password_hash (text not null), created_at (timestamp).

3. Add two API routes to src/server.js:
   POST /api/auth/register — accepts { email, password }, hashes password with bcrypt, 
   inserts into users table, returns { success: true }
   POST /api/auth/login — accepts { email, password }, checks against users table, 
   returns { success: true, userId } or 401 on failure

4. Add bcrypt to package.json dependencies.

Read dashboard/style.css and dashboard/index.html first to match the existing design.
